# Aura-cafe ☕

Aura-cafe is a cafe website I built as a mini project using Python and CSS.

## About the project
This project shows a simple, clean website for a cafe. I built it to practice web development and to learn how to host a project online.

## Tools used
- Python
- CSS
- Git and GitHub
- Render (for deployment)

## What I learned
- Building a website from scratch
- Styling pages with CSS
- Managing code using Git and GitHub
- Deploying a project online
## Features
- Customer ordering with a coffee and snack menu
- AI voice and text ordering powered by Groq (Llama 3.3)
- Staff queue page for baristas
- Instant bill and preparation time estimates
